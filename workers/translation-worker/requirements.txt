# Runtime dependencies for the VideoDubber translation worker (port 5102).
# Local/offline-first: Argos Translate provides on-device neural translation.
# Upper bounds are deliberate. These floors used to be open `>=`, and FastAPI no
# longer caps Starlette (0.136.3 declares a bare `starlette>=0.46.0`), so a
# rebuild from scratch could silently adopt a new Starlette MAJOR — a different
# HTTP stack in the same release, with no diff to show for it. Starlette is
# therefore pinned EXPLICITLY here: it is the real HTTP layer, and <1.3.1 carries
# GHSA-82w8-qh3p-5jfq / GHSA-jp82-jpqv-5vv3. Raise a ceiling deliberately, with a
# rebuild + the worker test suite, never by accident.
fastapi>=0.136,<0.142
starlette>=1.3.1,<2
uvicorn[standard]>=0.49,<0.54
# Pinned: the packaging swap to MiniSBD (see scripts/package/rthook_translation.py)
# depends on argostranslate's current sbd module shape — a bare `import stanza`
# plus MiniSBD selection from the package contents. Re-verify before bumping.
argostranslate==1.11.0
# Sentence splitting on onnxruntime; replaces stanza (which pulls ~580 MB of torch).
minisbd>=0.9.5,<1
pydantic>=2.13,<3
